# Homebrew Tap for Prismatic

Tap for **[Prismatic](https://github.com/szamski/Prismatic-for-macOS)** — control your
SteelSeries Arena 7 RGB lighting from the macOS menu bar, no SteelSeries GG required.

## Install

```sh
brew install szamski/tap/prismatic
```

## Update

```sh
brew upgrade --cask prismatic
```
